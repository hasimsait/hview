# Finished ceiling heights

Select a room's floor to open **Room & Floor Finish**. **Finished ceiling height (m)** sets the underside's elevation above the floor, independently for each room. The inspector shows the shared maximum and resulting drop in centimetres. Heights must be positive and cannot exceed the room's structural height or the shared maximum.

Clip-in ceilings default to a 15 cm drop when no explicit height is saved. Smooth gypsum retains the existing room height until lowered. An explicit height survives finish changes. **Reset ceiling height** removes that override and uses the current finish's default. **None** removes the rendered ceiling while retaining its settings.

The ceiling perimeter extends from the finished underside to the shared maximum. Walls, structural room heights and the plan maximum remain unchanged. Window-owned curtains and tracks, and wall-mounted cornices, follow height changes immediately, including undo/redo. Newly added ceiling-mounted accessories use the finished height of their placement room; existing independently placed assets retain their edited positions.

Heights persist in canonical plans (metres), legacy plans (centimetres), offline editors and exported viewers. The full editor has the same controls on desktop and iPad. The global **Ceilings** button continues to control visibility independently of the saved room settings.
